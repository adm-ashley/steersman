Find the Loop

Look at draw(). Every frame, the sketch does three things:

  1. sense() reads how bright the canvas is under each dot. The dots are reading the trails they drew themselves. That is the feedback loop.
  2. update() uses that reading to turn each dot. gain sets how strongly the reading steers them.
  3. render() draws the dots.

Now change let gain = 1.0; to let gain = 0;, save and refresh. Then try let gain = 3;.

What you should see: at 0 the dots wander at random; the loop is switched off. At 3 they react strongly to their own trails and start gathering into shapes.

Set the gain back to 1.0 before moving on.

Conversation After Pask

The work follows your mouse, but gets bored if you keep moving the same way.

Edit 1. Paste this at the very top of your sketch, above let gain.

let recent = [];
let attention = 1;

// How different is the mouse movement right now from the last 1.5 seconds?
function novelty() {
  const speed = dist(mouseX, mouseY, pmouseX, pmouseY);
  recent.push(speed);
  if (recent.length > 90) recent.shift();
  const avg = recent.reduce((s, v) => s + v, 0) / recent.length;
  return constrain(abs(speed - avg) / 20, 0, 1);   // 0 = same as usual, 1 = surprising
}

Edit 2. Replace the whole update() function with this.

function update(reading) {
  attention = lerp(attention, novelty(), 0.02);   // attention rises with surprise, fades with repetition
  agents.forEach((a, i) => {
    const target = atan2(mouseY - a.y, mouseX - a.x);
    a.a += sin(target - a.a) * 0.1 * attention * gain + random(-0.1, 0.1);
    a.x = (a.x + cos(a.a) * 1.5 + width) % width;
    a.y = (a.y + sin(a.a) * 1.5 + height) % height;
  });
}

Gains to try: 0, 1 and 3.

What you should see: At gain 0 the agents ignore you. At gain 1 and 3 they follow the mouse, but if you move in the same circle for 10 seconds they lose interest. Change how you move and they come back.

Search After Ashby

When the canvas gets too empty or too full, the system throws away its rules and picks new ones at random.

Edit 1. Paste this at the very top of your sketch, above let gain.

let rules = { turn: 1, speed: 1.5, fade: 8 };
let outside = 0;
let rewirings = 0;

// How full is the canvas? 0 = empty, 1 = full
function coverage() {
  loadPixels();
  let sum = 0, n = 0;
  for (let i = 0; i < pixels.length; i += 4 * 97) { sum += pixels[i]; n++; }
  return sum / n / 255;
}

// Pick new rules at random, like Ashby's Homeostat
function rewire() {
  rules = { turn: random(-2, 2), speed: random(0.5, 3), fade: random(2, 20) };
  rewirings++;
}

Edit 2. Replace the whole update() function with this.

function update(reading) {
  agents.forEach((a, i) => {
    a.a += (reading[i] - 0.5) * rules.turn * gain + random(-0.1, 0.1);
    a.x = (a.x + cos(a.a) * rules.speed + width) % width;
    a.y = (a.y + sin(a.a) * rules.speed + height) % height;
  });
  // Check every 10 frames; after about a second out of range, rewire
  if (frameCount % 10 === 0) {
    const cov = coverage();
    if (cov < 0.12 || cov > 0.6) outside++; else outside = 0;
    if (outside > 6) { rewire(); outside = 0; }
  }
}

Edit 3. Replace the whole render() function with this.

function render() {
  noStroke();
  fill(20, rules.fade);
  rect(0, 0, width, height);
  fill(240, 170, 50, 60);
  agents.forEach(a => circle(a.x, a.y, 3));
  fill(255);
  text(`rewirings: ${rewirings}`, 10, 20);
}

Gains to try: 0, 1 and 3.

What you should see: The rewirings counter goes up every time the system fails and picks new rules. Each rewiring changes how the image looks. Sooner or later it finds rules that keep it in range and stops changing.

Resonance After Lucier

The canvas is fed back into itself, slightly larger and blurrier, until only the process is left.

Edit 1. Paste this at the very top of your sketch, above let gain.

let feeding = true;

// Press the space bar to stop and start the agents drawing
function keyPressed() {
  if (key === ' ') feeding = !feeding;
}

Edit 2. Replace the whole render() function with this.

function render() {
  // Redraw the last frame, slightly larger: the loop
  const prev = get();
  push();
  translate(width / 2, height / 2);
  scale(1 + 0.005 * gain);
  image(prev, -width / 2, -height / 2);
  pop();
  if (frameCount % 5 === 0) filter(BLUR, 1);   // a little is lost each time

  if (feeding) {
    noStroke();
    fill(240, 170, 50, 60);
    agents.forEach(a => circle(a.x, a.y, 3));
  }
}

Gains to try: 0, 1 and 3.

What you should see: At gain 0 the marks just blur in place. At 1 and 3 they bloom outwards. Press the space bar to stop the agents and watch what the loop does on its own.

Exposure After Haacke

Agents compete for a resource on the ground. The more they have, the more they can take.

Edit 1. Paste this at the very top of your sketch, above let gain.

const COLS = 30;   // the ground is a 30 x 30 grid
let res = [];      // how much resource is left in each square

function cellOf(a) {
  const cx = constrain(floor(a.x / width * COLS), 0, COLS - 1);
  const cy = constrain(floor(a.y / height * COLS), 0, COLS - 1);
  return cx + cy * COLS;
}

Edit 2. Replace the whole setup() function with this.

function setup() {
  createCanvas(600, 600);
  pixelDensity(1);
  for (let i = 0; i < COLS * COLS; i++) res.push(1);
  for (let i = 0; i < 200; i++) {
    agents.push({ x: random(width), y: random(height), a: random(TWO_PI), wealth: 0 });
  }
}

Edit 3. Replace the whole update() function with this.

function update(reading) {
  agents.forEach(a => {
    const c = cellOf(a);
    const take = min(res[c], 0.02 * (1 + a.wealth * gain));   // the rich take more
    res[c] -= take;
    a.wealth += take;
    a.a += (1 - res[c]) * random(-1, 1);   // wander more where the ground is bare
    a.x = (a.x + cos(a.a) * 1.5 + width) % width;
    a.y = (a.y + sin(a.a) * 1.5 + height) % height;
  });
  for (let i = 0; i < res.length; i++) res[i] = min(1, res[i] + 0.001);   // slow regrowth
}

Edit 4. Replace the whole render() function with this.

function render() {
  background(20);
  noStroke();
  const s = width / COLS;
  for (let i = 0; i < res.length; i++) {
    fill(60, 110, 100, res[i] * 255);
    rect((i % COLS) * s, floor(i / COLS) * s, s, s);
  }
  fill(240, 170, 50, 180);
  agents.forEach(a => circle(a.x, a.y, min(30, 2 + sqrt(a.wealth) * 2)));
}

Gains to try: 0, 1 and 3.

What you should see: The green ground empties where agents feed. At gain 0 everyone stays roughly the same size. At higher gains a few agents grow much bigger than the rest.

Control After Beer

A controller keeps the average position of all agents in the centre. It only sees the average.

Edit 1. Paste this at the very top of your sketch, above let gain.

let avg = { cx: 300, cy: 300 };   // everything the controller knows

Edit 2. Replace the whole sense() function with this.

function sense() {
  const cx = agents.reduce((s, a) => s + a.x, 0) / agents.length;
  const cy = agents.reduce((s, a) => s + a.y, 0) / agents.length;
  avg = { cx, cy };
  return avg;
}

Edit 3. Replace the whole update() function with this.

function update(r) {
  // The controller wants the average in the centre, and pushes everyone to get it there
  const errX = width / 2 - r.cx;
  const errY = height / 2 - r.cy;
  agents.forEach(a => {
    a.a += random(-0.3, 0.3);
    a.x = constrain(a.x + cos(a.a) * 1.5 + errX * 0.01 * gain, 0, width);
    a.y = constrain(a.y + sin(a.a) * 1.5 + errY * 0.01 * gain, 0, height);
  });
}

Edit 4. Replace the whole render() function with this.

function render() {
  noStroke();
  fill(20, 8);
  rect(0, 0, width, height);
  // Colour shows crowding, which the controller never sees
  agents.forEach(a => {
    const crowd = agents.filter(o => dist(a.x, a.y, o.x, o.y) < 20).length;
    fill(map(crowd, 1, 15, 60, 255), 120, 80, 120);
    circle(a.x, a.y, 3);
  });
  // The white ring is the controller's whole view of the world
  noFill();
  stroke(255);
  circle(avg.cx, avg.cy, 16);
}

Gains to try: 0, 50 and 250 (this stance needs bigger numbers).

What you should see: The white ring is the average. At 50 the controller holds it in the centre, even while the coloured agents clump and scatter. At 250 it over-steers and the whole group swings back and forth.

Conditions After Cheng

A population that is born and dies on its own, with no ending and no reset.

Edit 1. Paste this at the very top of your sketch, above let gain.

let popHistory = [];

Edit 2. Replace the whole sense() function with this.

// The system reads its own population, as it was two seconds ago
function sense() {
  popHistory.push(agents.length);
  if (popHistory.length > 120) popHistory.shift();
  return popHistory[0];
}

Edit 3. Replace the whole update() function with this.

function update(pastPop) {
  // The bigger the population was, the fewer births now
  const pBirth = constrain(0.01 * (1 - gain * pastPop / 300), 0, 0.02);
  const born = [];
  agents.forEach(a => {
    a.a += random(-0.2, 0.2);
    a.x = (a.x + cos(a.a) * 1.5 + width) % width;
    a.y = (a.y + sin(a.a) * 1.5 + height) % height;
    if (random() < pBirth && agents.length < 2000) {
      born.push({ x: a.x, y: a.y, a: random(TWO_PI) });
    }
  });
  agents = agents.filter(() => random() > 0.004).concat(born);   // a small chance of death each frame
}

Edit 4. Replace the whole render() function with this.

function render() {
  noStroke();
  fill(20, 8);
  rect(0, 0, width, height);
  fill(240, 170, 50, 60);
  agents.forEach(a => circle(a.x, a.y, 3));
  fill(20);
  rect(0, 0, 170, 28);
  fill(255);
  text(`population: ${agents.length}`, 10, 19);
}

Gains to try: 0, 1 and 3.

What you should see: Watch the population number. At gain 0 it keeps growing until it hits the limit. At 1 it levels off. At 3 it swings between booms and crashes, because it is reacting to where it was two seconds ago.

Troubleshooting

The Canvas Goes Black, or Fills Solid White
At some gains the system dies out or runs away. That’s a real result; try the other gains on your stance’s list.
The Sketch Is Very Slow
Change the 200 in setup() to 100 for fewer agents.
